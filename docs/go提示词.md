**【角色设定与目标】**
请帮我使用 go+viva 编写一个类似 Postman/Apifox 的 HTTP 接口管理与测试工具，名字叫 GoRester。请基于以下详细的 UI 布局和功能交互需求进行代码生成：
viva 是跨平台ui，组件和api文档参考 https://vivaui.dev/
**【整体布局架构】**
顶部是标签栏，主页和其他打开的接口项目，有x标记，可关闭。
页面整体采用左右分栏布局（左侧为固定宽度的导航栏，右侧为自适应的主工作区）

**【详细模块与功能描述】**
程序打开后默认显示主页，主页内容是每个方格子形状的项目，每个格子顶部项目名称，下方是项目说明。最左上角的个子是一个“新加”的格子，底色蓝色。点击新加，弹出窗口，上面输入项目名称，下方输入简洁。点击某个项目格子，就打开了项目，显示以下内容
左右布局约1:4，右侧上下布局约3:2
**1. 左侧边栏：接口管理区 (Sidebar)**
*   **顶部操作区**：包含一个搜索框（带搜索图标）、一个过滤按钮（漏斗图标）和一个主色调的“新建”按钮（加号图标，新建文件夹或接口）。
*   **目录树 (Tree View)**：
    *   目录树最右侧可以有导入导出按钮，
    *   支持多级折叠/展开。右键文件夹可新加接口
    *   在文件夹下，展示具体的接口列表，
    *   接口列表最左侧最好有字母图标，标记接口的方法类型，如GET，标记蓝色G，POST标记蓝色P，del 标红色D
    *   当前选中的接口节点需有高亮背景状态。
    *   每个接口可以展开显示已经保存的接口用例
    *   点击接口是编辑接口，点击用例是打开该接口的用例


**2. 右侧主工作区 (Main Workspace)**
主工作区上下分为“请求配置区”和“响应结果区”。

*   **2.1 工作区顶部标签页**：
    *   包含“项目概览”、打开的接口等可关闭的 Tab，右侧带有“+”新建按钮，新建就是新建接口。
    *   **右上角操作区**：包含一个“环境下拉选择框（用于切换接口环境，如开发、测试、生成），以及一个菜单折叠图标，点击折叠图标可以编辑环境，如基本地址base_url,如全局变量，全局header，默认耗时等。

*   **2.2 URL 请求构造栏**：
    *   **Method 选择器**：左侧为一个下拉框（Select），当前显示绿色的“GET”，用于选择 HTTP 请求方法。支持get、put、post、delete、head、option
    *   **URL 输入框**：占据主要宽度的文本输入框，展示当前请接口路径，注意这里请求时需要拼接环境变量的base_url。
    *   **操作按钮组**：右侧包含一个主色调的“发送”按钮（带下拉箭头）、“保存”按钮按钮以及“保存为用例”按钮，保存时，允许选择目录树的文件夹，保存用例，自动保存到对应接口的树下。

*   **2.3 请求参数配置区 (Request Config Tabs)**：
    *   包含一排 Tab 切换：Params、Body、Cookie、Header、Auth。
    *   **Body 配置面板（当前激活状态）**：
        *   **格式切换子 Tab**：包含 none, form-data, x-www-form-urlencoded, json, xml, raw 等选项，当前选中 `x-www-form-urlencoded`。form-data支持文件类型
        *   **键值对表格 (Data Table)**：包含表头“参数名”、“类型”、“示例值”、“说明”。表格行内支持输入，示例值带有必填星号（*）标识。
        *   如果是json或xml，支持内容格式化和语法高亮

*   **2.4 响应结果展示区**：
    *   **结果 Tabs**：包含 Body（当前激活）、Cookie、Header 等切换项。点击不同的tab显示对应的响应结果。
    *   **工具栏**：左侧包含格式化下拉框（Pretty）、语言下拉框（JSON）、编码下拉框（utf8）；右侧包含提取、下载、复制、搜索等小图标按钮。
    *   **内容展示区**：一个带有行号的响应内容区域，展示格式化且带有语法高亮的 JSON、xml 响应数据（如果内容过长 可以不高亮、不格式化）。

*   **2.5 状态栏**：
	* 显示 当前接口的耗时ms、接口返回状态码
  
**【数据要求】**
- 接口支持按项目导入导出openapi 3.0格式。
- 所有的数据保存到用户～/gorester/目录下。
- 所有的数据用json格式保存
- 一个项目一个文件夹，名字用项目名称


**【性能要求】**
- 每个项目复用http client
- 注意内存占用，及时释放接口的返回值内容
- 每个接口默认耗时30秒
